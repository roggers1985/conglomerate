# Review: Keep behaviour the same during a migration

## Summary

The change does what the spec says. All eight criteria are met, their evidence holds, the named tests pass, and `bun run check` passes (492 tests, 101 doctest examples). The gate code is small and reads `migration-plan.md` through the existing change-document reader, which is bounded and refuses symbolic links (ADR 0060).

What matters most: the skills don't yet say exactly what "unchanged" means for the behaviour test. Read literally, the review's new check flags every side-by-side migration and every intended difference, and it misses a re-recorded golden master (findings 1 and 2). The build and review rules also don't fit a schema-only migration or the quick track, and planning doesn't make the behaviour test the first task (findings 3 to 5). None of these breaks a criterion; they are gaps in the text that a real migration would hit.

**Round 2** (fresh reviewer, 2026-10-10, with the mutation check). The change meets all 14 criteria, and the evidence in `verification.md` holds. `bun run check` passes with 496 tests and 101 doctest examples. Round 1's fixes 1 to 10 hold. Every code break of the mutation check made a test fail; the only breaks that stayed green were two edits to the content of the AC-4 template (finding 16). The new two-agent build flow is sound for an ordinary task, but it doesn't cover a migration's tasks after T-1 (12), the single-agent prompt (13) or a task without a `Tests` line (14). AC-13's scope conflicts with the repository's one-line summaries on internal functions, which is the owner's call (15). Findings 12 to 22 are new, and finding 4 stays fixed.

**Round 3** (fresh reviewer, 2026-10-10, checking the fixes). Findings 12 to 22 are fixed, and the owner's decisions on 15 and 18 were carried out as decided. `bun run check` passes with 497 tests and 101 doctest examples. The strengthened AC-4 template test fails on both breaks tried (the "its form" bullet and the "every file" bullet removed). The fixes added five new findings, 23 to 27; the one that matters is 23, where the quick-track prompt contradicts the quick-track migration rule. Round 3 is the last round at the default of three, so findings 23 to 27 are put to the owner.
