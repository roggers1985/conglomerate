# Review: Write documentation for people

## Summary

The change does what the spec asks: all eight criteria are met, and `bun run check`, the template test and both change checks pass. No gate-checked heading, label or parsed word changed, and the rewritten pr-body plan keeps every fact. What matters most: the audience rule leaves people-facing files outside `docs/` unclassified (`GLOSSARY.md` above all), and the plan template lost an instruction in its rewrite, the very loss of precision the convention forbids.
