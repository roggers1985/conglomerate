# Checkup: claude-code-platform (2026-11-09)

Model: Claude Sonnet 5.5
Previous report: docs/checkups/claude-code-platform/2026-09-29.md

## Summary

The plugin's manifests, skill and agent frontmatter and hooks still match Claude Code's documented platform, and `claude plugin validate plugins/factory` passes. One real problem: the session-start hook prints 13,127 characters of context, and Claude Code caps each hook string at 10,000. Claude therefore receives only a 2,000-character preview of the conventions plus a file path, and never sees the autonomy rules or the model routing table. I confirmed this with a live `claude -p` run against the plugin. The window reviewed is Claude Code 2.1.285 to 2.1.319 (the previous report ended at 2.1.284).

## Fixed in this run

- Nothing in the plugin. Finding 1 changes how the plugin is structured, so under this checkup's rules it needs an ADR first. This commit only adds this report.

## Needs a human

- **Fix the 10,000-character cap on the session-start context (finding 1).** Proposal: split the output into three hook entries in `plugins/factory/hooks/hooks.json`, each printing one part (core conventions, autonomy and settings, model routing). The cap applies per string, even across several hooks for the same event, so each part stays under it. `core.md` alone is about 9.8 KB, so also trim it a little for headroom. Add a test that fails when any part passes 10,000 characters, so it cannot grow back silently. This needs an ADR, because it amends ADR 0008 and 0014's mechanism; run `bun run generate` afterwards.
  - Alternative: trim everything into one string under the cap. Not recommended, since the three parts total about 13 KB and the conventions would have to lose a quarter of their content.
  - Until this is fixed, every session, subagent included, works from a truncated rule set.
- **Publishing metadata (finding 2).** Proposal: if the repository goes public (ADR 0050), add a square PNG icon (512 to 2048 px) via `icon` in `plugin.json`, and an install line in `plugins/factory/README.md`. Nothing to do while it stays local.
- **Copilot (finding 3).** Proposal: keep it deferred (ADR 0002). If it comes up again, test whether Copilot CLI can install this plugin from `.claude-plugin/marketplace.json`, or what a Copilot-format `plugin.json` would need to add. Do not build until tested.
